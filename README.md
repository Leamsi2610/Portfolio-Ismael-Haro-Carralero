# DESCRIPCIÓN Y PROPÓSITO DEL PROYECTO

El proyecto consiste en la creación de un portfolio web profesional para poder enseñar todos mis trabajos como ilustrador
y diseñador gráfico. El próposito de este proyecto es realizar un buen porfolio que futuros clientes puedan consultar para
ver mis trabajos y poder contactar conmigo.

# STACK TECNOLÓGICO

- HTML5: Estructura del sitio web
- CSS: Diseño y estilos de la web
- JAVA SCRIPT
- GITHUB: Donde tengo el repositorio
- GITHUB PAGES: Donde está publicada la página
- IMAGEKIT.IO: API que me permite colocar imágenes en la web

# GUÍA DE PERSONALIZACIÓN

# POLÍTICA DE USOS DE IA

Para este proyecto he utilizado la IA en un par de ocasiones para poder obtener un diseño más profesional y acorde a mi idea inicial.

1. FASE 1: PLANIFICACIÓN

   Antes de escribir cualquier código, se solicitó a la IA un plan detallado de la tarea o feature. Estos planes se documentaron en archivos independientes dentro de `docs/plan1.md`, `docs/plan2.md`, y `docs/plan3.md`, incluyendo el prompt, la respuesta de la IA y notas sobre la implementación.

2. FASE 2: IMPLEMENTACIÓN

   Solo después de documentar y validar el plan, se llevó a cabo la implementación en el código. Esto garantiza que la IA se utiliza como herramienta de apoyo en la planificación y no como un reemplazo del desarrollo propio.

# OTROS COMENTARIOS

Para ser totalmente sincero he batallado bastante con el proyecto para poder sacarlo adelante. Desde layouts que comenzaban a deajustarse hasta animaciones que no funcionan bien. Al final, he conseguido adaptar el resultado a la idea orginal, pero dejando atrás otras cosas que no he podido meter por más que lo intentara, como por ejemplo la opción entre distintos modos de color, pero que, gracias al proceso constante y seguido, he sabido solventarlo todo para obtener un proyecto del que estoy orgulloso.
