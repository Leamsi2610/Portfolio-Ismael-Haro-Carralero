# SECCIÓN TRABAJOS

# PROMPT A LA IA

- ¿Cómo puedo hacer una nueva sección para poner los diferentes trabajos con texto e imágenes?

# RESPUESTA DE LA IA

- La IA propuso estructurar la sección de proyectos mediante un contenedor principal y un grid para organizar los trabajos. Cada proyecto se compone de un título, una rejilla de imágenes colocadas horizontalmente y un texto descriptivo. Para evitar saltos visuales entre imágenes de diferentes proporciones, se recomendó unificar su comportamiento mediante CSS Grid y controlar su tamaño con width: 100% y object-fit, asegurando una correcta adaptación a distintos tamaños de pantalla mediante media queries.

# IMPLEMENTACIÓN

- Se implementó una sección de proyectos basada en CSS Grid, donde cada trabajo incluye un título, un conjunto de imágenes alineadas horizontalmente y un texto descriptivo debajo. Tras varias interacciones, se aplicó la solución final recomendada por la IA para evitar saltos visuales al usar imágenes de diferentes proporciones, asegurando un diseño estable y responsive en distintos tamaños de pantalla.
