# GITIGNORE

# PROMPT A LA IA

- ¿Qué debe incluir un archivo .gitignore completo y sencillo para un portfolio web, excluyendo node_modules, archivos del sistema y configuraciones de IDE?

# RESPUESTA DE LA IA

- La IA explicó qué es un archivo .gitignore y propuso incluir en él las carpetas de dependencias de Node, archivos generados por el sistema operativo y configuraciones locales de editores de código. También recomendó mantener el archivo sencillo, adaptado a un proyecto web básico, evitando complejidad innecesaria.

# IMPLEMENTACIÓN

- Se creó un archivo .gitignore en la raíz del proyecto con exclusiones para node_modules, archivos del sistema operativo y configuraciones de editores de código. La solución final se ajustó al briefing del proyecto y se mantuvo deliberadamente sencilla.
